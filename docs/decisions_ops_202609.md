## 2. Airbnbリスティング — タイトル改善は10月に実施

- **競合50件は全件「駅名＋最大人数＋キャナルシティ＋駐車場」のSEO詰め込み型**。自社2棟は**キャナルシティが両棟とも欠落**し、語順も後ろ重心（検索結果に見えるのは先頭30〜35文字のみ）
- 高砂は1ページ目表示率58.9%に対し**検索→閲覧43.6%**と低い＝タイトル・カバー写真が弱点。閲覧→成約は5.65%と高いので「見せれば売れる」
- **実施は10月**（高砂値上げの判定期間と変数を分けるため）。ai.yamadaから10/1朝にリマインドメールを予約済み
- 改善案（確定）:
  - 清川: `最大8名・天神博多10分｜キャナルシティ近く｜新築109㎡・5名まで1人1ベッド｜駐車場無料`
  - 高砂: `渡辺通駅5分・最大6名｜キャナルシティ徒歩圏｜洗面台3・1人1ベッド｜大型車OK駐車場`

## 3. チャネル — Beds24 Marketplace の仕分け

| アプリ | 判断 | 理由 |
|---|---|---|
| **Stripe** | ○ 接続する | P1のMS3で必須。ホスト型予約ページにも決済を付けられる |
| **Google Ads（Hotel Ads / 無料予約リンク）** | △ **P1完成後** | ランディング先はOTA不可＝自社予約ページ必須。手数料ゼロのGoogle直販導線 |
| Vrbo | △ 優先度低 | 福岡に158件掲載あり（＝空白ではない）。ただし**競合トップ勢は1件も載せていない**＝「勝者の増幅装置」ではなく「埋まらない在庫の受け皿」。接続するなら清川のみ・補完チャネルとして |
| Expedia | △ Vrboの成績を見てから | 客層がVrboと重複 |
| **Pricelabs / RoomPriceGenie** | ✕ **永久に不要** | 自社戦略は「競合AIが遠い日付を高くする裏をかく固定適正価格」。導入は武器の放棄 |
| Besty AI / bnbgenius | ✕ 現時点で不要 | メッセージ対応は運営会社の業務。二重対応は事故のもと。3号棟の自社運営パイロット時に再検討 |
| RemoteLock / TTLock | ✕ 現時点で不要 | 直営棟ができてから |

## 5. 運営会社への依頼リスト（未実施）

1. **ガイド1枚シート（QR付き）の掲示** — メッセージ実測で月150〜170通、うち約8割が同じ5問（**Wi-Fiパスワード・チェックイン/荷物預け・ゴミの出し方・洗濯機・お湯の出し方**）。全部ガイドブックに書いてあるが「開かれていない」。玄関とリビングの目線高さに韓・繁中・英の3言語で貼る
2. **レビュー依頼文の追加** — チェックアウト後メッセージに依頼文が入っていない可能性が高い（★4.77/47件・★4.67/36件は「頼まずにこれ」）。件数の積み上げ速度が変わる
3. **清掃ブロックの精査** — Airbnb実績で7月14泊・直近29日6泊がブロック。全室売り切れる状況ではブロック1泊＝約¥4〜5万の機会損失。必要日数の根拠を報告してもらう
4. Booking.com の非返金プラン併売・繁忙日フレキシブル閉鎖
5. Bookingコンテンツの完全化
