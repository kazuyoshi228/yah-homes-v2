## 4. 発注者決定: 乳幼児の人数カウント（2026-09-08）

**決定: 年齢にかかわらず、乳幼児（添い寝含む）も宿泊人数に数える。**

- 背景: 上記2件でAIが1歳児を1名として5名で料金照会した。追加1名 5,000円/泊のため、
  「添い寝は数えない」ポリシーだった場合は見積もり過大（3泊で15,000円）となる論点を
  発注者へ提示 → 「宿泊人数に数える」と決定。AIの挙動は正しかったことが確定。
- 反映（2026-09-08 実施済み）: `property_facts/{kiyokawa,takasago}.chatInfo` の
  「予約変更・料金」カテゴリ、「大人・子どもの人数変更」行の直後に以下を追加。
