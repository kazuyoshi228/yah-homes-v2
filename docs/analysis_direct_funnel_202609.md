## 1. 結論 — 離脱の主因は価格でもUIでもなく「在庫」

直近1週（8/31〜9/6）のユーザー数ベースのファネル:

| 段階 | 人数 | 前段からの残存 |
|---|---:|---:|
| 空室を検索した（availability_requested） | 81 | — |
| **満室画面を見た（sold_out_viewed）** | **70** | **86%が満室で終了** |
| 結果を見られた（availability_result_viewed） | 32 | 40% |
| 日付を選んだ（dates_selected） | 22 | 27% |
| 決済画面まで来た（checkout_viewed） | 3 | 4% |
| 購入（実客） | 0 | — |

**空室検索の86%が「満室」で行き止まりになっている。** 月換算で約280人。2棟730泊/年という供給では構造的で、価格調整・UI改善・広告では解けない。**増床（六本松2027/1・大手門2027/4）が最大のレバー**であることを、初めて自社データが直接示した。

補足: 10月は「2棟で3連泊できる開始日が1通りしかない」（空室アラート実装時の実測）。3泊以上を求めるクジラ層（SG/UK/AU＝1組¥217〜272K）を在庫の細切れで取り逃している可能性がある。**LOS 2.5泊は需要の性質ではなく在庫制約かもしれない**——増床後に検証する。
